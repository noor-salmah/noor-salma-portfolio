# Portfolio Template

A fresh multi-page portfolio site — same section structure as before (Home, About,
Projects, Skills, Certificates, Media, Journey, Contact), completely new design:
a berry/raspberry/gold color palette, a fixed left sidebar navigation, a split-screen
hero, and a "scrapbook" card style (tilted, pinned polaroid look) for projects,
skills, and certificates.

## What's already done
- All 8 pages built and linked together
- Full color/type/layout system in `css/style.css`
- Mobile-responsive (sidebar collapses into a top bar + drawer on small screens)
- Scroll-reveal animations, animated stat counters, active-page nav highlighting
